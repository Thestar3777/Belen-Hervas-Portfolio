## 🌟 Introduction
> **"Crafting beautiful, responsive websites with clean code and creative design"**

I am **Belen Hervas** (Stella), a passionate developer dedicated to building user-friendly and visually appealing web experiences. This site is designed to introduce myself to potential clients and employers.

## 🚀 Features

* **Responsive Hero Section:** A clean landing area with clear "View My Work" and "Get In Touch" calls to action.
* **About Me:** A personal introduction section ("Get to Know Me").
* **Navigation:** Smooth scrolling links to About, Skills, Projects, and Contact sections.
* **Modern UI:** Features a custom illustration and a clean, purple-themed color palette.

## 🛠️ Technologies Used

* **HTML5:** For semantic page structure.
* **CSS3:** For styling, layout (Flexbox/Grid), and responsive design.
* **JavaScript:** For interactive elements (like the navigation or buttons).
